# Website Integration

`intent-driven-plugin` is designed to be usable from Claude Code while working inside any software
repository, including projects referenced from https://intent-driven-engineering.com.

There is no special integration code, embed, or API between this plugin and the website — the
plugin works the same way in every repository. This document exists so that the website's
documentation/onboarding pages can link to a single, stable installation path.

## What the website should link to

- **Install:** point readers to [INSTALLATION.md](INSTALLATION.md) (the two `/plugin` commands to
  add the marketplace and install the plugin).
- **Usage:** point readers to [USAGE.md](USAGE.md) for what `/intent-driven-plugin:intent-check`
  reports and its read-only guarantee.
- **Repository:** https://github.com/kendallmark3/intent-driven-plugin

## Positioning

For intent-driven-engineering.com content, the plugin can be described as: a free, credential-free
first step for any repository — run one command to get a concrete readiness assessment and a
safely-scoped first intent to try, before adopting a broader intent-driven workflow.
